About GeneCare AI

GeneCare AI is an educational health-risk screening platform designed to show how machine learning, explainability, APIs, and responsible engineering can work together.

Our Goal

Make machine-learning health-risk screening easier to understand.

Responsible AI

Model predictions are estimates, not medical diagnoses.

Technology

Simple, understandable frontend engineering supports the ML system.

Technology

Clear at the surface. Serious underneath.

The interface uses HTML, CSS, and JavaScript. The connected backend uses FastAPI, with Scikit-learn, XGBoost, and SHAP for the active ML pipeline.

  • Frontend — HTML / CSS / JavaScript
  • Backend — FastAPI
  • ML — Scikit-learn / XGBoost
  • Explainability — SHAP
